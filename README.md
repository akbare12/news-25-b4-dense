Also inside: Gaza, the Cairo tanker fire (31 killed), 76 hostages freed in
Cartagena, the first foreign astronaut aboard Tiangong, the Australia–Solomon
Islands security treaty, the Iowa explosives detonation, Abrego Garcia's arrival
in Madrid, Nvidia's downgrade watch, the first-ever weather postponement of the
100th Macy's parade, and US Q3 GDP at 4.3%.

All drawings are original vector art made in code — no photos. Every story is
dated Wednesday 25 November 2026; events from other days are listed in the
DATE CHECK box at the bottom of the image.

## How it is built

`gen.py` renders `entry.png` (1024×1024) with Pillow. `main.py` is standard
library only: it copies `entry.png` next to it into
`$MAKEFUN_OUTPUT_DIR/entry.png`.
